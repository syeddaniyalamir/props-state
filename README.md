# Props & State 🚀

A beginner-friendly React practice project focused on understanding the core concepts of **Props and State** through hands-on coding.

## 📚 What I'm Learning

- Understanding React Components
- Passing data between components using Props
- Passing functions as Props
- Managing component state using `useState`
- Handling events in React
- Understanding parent-child component communication
- Updating UI dynamically using State

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## 🎯 Purpose

The purpose of this project is to strengthen my React fundamentals through practical implementation and improve my ability to build React applications independently.
